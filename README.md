# Personal Blog – React

## Description
A simple personal blog built with React and Vite to demonstrate reusable components and passing data through props.

## Components
- **App:** Main component connecting all other components.
- **Header:** Displays the blog name.
- **About:** Displays the blog logo and description.
- **ArticleList:** Renders a list of blog posts using `map()`.
- **Article:** Displays an individual post's title, date, and preview.

## Component Structure
```text
App
├── Header
├── About
└── ArticleList
    └── Article
```

## Installation
```bash
npm install
```

## Run the Project
```bash
npm run dev
```

Open the local URL provided in the terminal.

## Run Tests
```bash
npm test
```

## Technologies
React, JavaScript, JSX, CSS, Vite, and Vitest.
